## 알려진 점

- 동영상의 연표와 큰 제목 글자, 스태프 롤은 원본 그대로입니다.
- 인터넷 메뉴는 번역하지 않았습니다.
- 칸이 좁은 곳은 띄어쓰기를 줄이거나 낱말을 줄였습니다.

## 저장소 구성

- `tools/` — 추출, 빌드(`build.py`), 검산(`verify.py`), 그림·동영상 자막, 배포 묶음(`make_dist.py`)
- `data/번역/` — 번역 합본(`ko.tsv`), 동영상 자막(`movie_ko.tsv`)
- `docs/` — 조사 기록

원본 게임 이미지와 빌드 결과물은 포함하지 않습니다.
